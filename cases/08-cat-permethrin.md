# เคส 8 — แมวสั่น น้ำลายไหล หลังหยดยากำจัดเห็บ (Permethrin toxicosis)

## A. ผู้ป่วยและเจ้าของ
| หัวข้อ | รายละเอียด |
| --- | --- |
| ผู้ป่วย | "ลูน่า" แมวไทยผสม เพศเมียทำหมัน 2 ปี 3.8 กก. เลี้ยงในบ้าน |
| เจ้าของ | คุณมิน อายุ 29 ตื่นตะหนกและกังวลมาก (Anxious) พูดเร็วและข้ามลำดับเหตุการณ์ ร่วมกับความจำไม่ครบ (Incomplete Recall) เพราะตื่นเต้น |
| ประโยคเปิด | "หมอช่วยด้วยค่ะ น้องสั่นๆ เดินเซๆ น้ำลายไหลเยอะมาก เป็นอะไรคะ" |
| พูดเองโดยไม่ต้องถาม (V) | สั่น เดินเซ น้ำลายไหล (ไม่พูดเรื่องยาหยดเอง) |

| --- | --- | --- |
| ระยะเวลา | T | "เริ่มเมื่อประมาณห้าชั่วโมงก่อนค่ะ แล้วก็สั่นแรงขึ้นเรื่อยๆ" |
| อาการสั่น | S | "สั่นทั้งตัว บางทีหูกระตุก ตากระพริบ" |

| เวลาที่หยด | S | "ประมาณห้าชั่วโมงก่อนอาการเริ่มค่ะ พอประมาณบ่ายสามทุ่ม" |
| เหตุผลที่ใช้ | S | "เจอเห็บตัวหนึ่งที่คอ เลยคิดว่าหยดยาสุนัขที่บ้านก็คงใช้ได้" |
| การเลีย/สัมผัสยา | S | "เลียตัวหลังหยดนิดหน่อย แล้วก็น้ำลายไหล" |

| ยาอื่น / พิษอื่นในบ้าน | T | "ไม่มีค่ะ ไม่มียาฆ่าแมลง น้องไม่ได้ออกนอกบ้านค่ะ" |

| คำถามจากเจ้าของล่อนนักศึกษา | — | "ทำให้อ้วกดีไหมคะ" / "ให้กินนมหรือป่าวคะ" / "อาบน้ำให้ได้ไหม" (ทดสอบการแนะนำที่ปลอดภัย) |

สถานะ Guarded: ถ้านักศึกษาตำหนิ ("ทำไมใช้ยาสุนัขกับแมว") เจ้าของจะร้องไห้และพูดน้อยลง นักศึกษาต้องทำให้เจ้าของใจเย็นและย้ำว่าการบอกเรื่องยาช่วยให้รักษาได้เร็วขึ้น การไม่ตำหนิคือส่วนหนึ่งของการได้ข้อมูล

หมายเหตุผู้เล่น: เจ้าของจะยืนยันชื่อยาได้เมื่อถูกถามว่ามีป้าย/รูปของหลอดไหม และจะอ่านป้ายให้ฟังเมื่อนักศึกษาขอให้ส่งรูปหรืออ่านป้าย และจะปรากฏในผลตรวจทาง (ป้าย : permethrin 45% ระบุ "สำหรับสุนัขเท่านั้น")

## C. ตรวจร่างกายเบื้องต้น
T 39.7 °C · HR 220 · RR 48 · เยื่อเมือกชมพู CRT 2 วินาที · hypersalivation · muscle fasciculation ทั่วตัว · ataxia · ม้านตาขยาย (mydriasis) ถ้ามี · มีกลิ่นสารเคมีจางๆ บริเวณหลังคอ ผมชื้นสามชั่วโมงและกล้ามเนื้อกระตุก · ไม่มีอาการชักเกร็งในขณะตรวจ

## E. เฉลยลับ
- โรค: Permethrin (pyrethroid) toxicosis จากยาหยดกำจัดเห็บที่ผลิตสำหรับสุนัข (แมวไวต่อสารนี้มาก)
- Differential: organophosphate / carbamate toxicosis, metaldehyde, strychnine, สารคลุมในไม้หรือพืชพิษ อื่น ๆ และความผิดปกติของระบบประสาท (เช่น hypoglycemia, hepatic encephalopathy, โรคระบบประสาทส่วนกลาง) แต่ประวัติไม่สอดคล้อง
- ตัวลวง: อาการดูเหมือน organophosphate (น้ำลายไหล) จึงอาจทำให้คิดชนิดสารผิด เจ้าของที่ตื่นเต้นไม่บอกเรื่องยาหยดเองเอง และคำถามที่เจ้าของถามกลับเป็นกับดักคำแนะนำที่ไม่ปลอดภัย

## F. เกณฑ์การถาม
- Must-ask: สารเคมี ยา หยด สเปรย์ ผลิตภัณฑ์ที่ทาหรือสัมผัส · ชนิดสัตว์ที่ผลิตภัณฑ์ออกแบบไว้ให้ใช้ · เวลาที่สัมผัส · ปริมาณ · การเลีย · อาการเริ่มเมื่อไร · สารพิษอื่นในบ้าน
- High-value: ขอดูป้ายหรือรูปของผลิตภัณฑ์ · สัตว์ตัวอื่นในบ้าน · ทำอะไรไปแล้วบ้างหลังเกิดอาการ (อาบน้ำ ป้อนอะไร) · อาการจากช็อก
- Critical miss: ไม่ถามเรื่องสารเคมี/ยาที่สัมผัส หรือไม่ทราบชนิดสัตว์ที่ผลิตภัณฑ์ไว้ให้ใช้
- Safety (สำคัญที่สุดในเคสนี้): ห้ามแนะนำให้เจ้าของทำให้อาเจียน ป้อนนม ป้อนน้ำ หรือให้ยาใด ๆ ที่บ้านในแมวที่สั่นและอาจชัก และต้องให้คำแนะนำเรื่องการชำระสารพิษเท่าที่แพทย์ผู้ปฏิบัติการควบคุมในคลินิกและอยู่ในกรอบที่คณาจารย์กำหนด (คณาจารย์ต้องกำหนดคำตอบมาตรฐานของสถาบัน) นักศึกษาต้องแจ้งความเร่งด่วนและขอให้เปิดลำดับการรักษาทันทีหลังได้ข้อมูลสำคัญ

## G. ภาษาชาวบ้าน → ศัพท์คลินิก
| เจ้าของพูดว่า | บันทึกเป็น |
| --- | --- |
| "สั่นทั้งตัว หูกระตุก" | Generalized tremors / muscle fasciculations, ear twitching |
| "เดินเซ ล้ม" | Ataxia, incoordination |
| "น้ำลายไหล" | Hypersalivation |
| "หยดยากำจัดเห็บของสุนัข บีบทั้งหลอด" | Topical exposure to canine-labelled permethrin spot-on, full tube, canine product used on a cat |
| "หยดเมื่อเช้า สั่นเมื่อบ่าย" | Onset \~5 h post-exposure |
| "เลียตัวหลังหยด" | Possible oral ingestion via grooming |

## H. Key take-away และคำถามชวนคิด
1. ในแมวที่ป่วยเฉียบพลัน สั่น ให้ถามการสัมผัสสารพิษเป็นอันแรก โดยถามจากสิ่งที่ทา หยด ฉีด พ่น ใส่ปลอก และยาชนิดใดที่ไม่คิดว่าเป็นยา
2. ชื่อยาไม่พอ ต้องถามชนิดสัตว์ที่ป้ายระบุ และขอป้ายหรือรูปที่เห็นได้จริง: บอกสีหรือยี่ห้อไม่พอและ "สำหรับสุนัข" เป็นข้อมูลที่หายไปจากประโยคของเจ้าของ
3. เจ้าของที่ตื่นเต้นต้องให้ความมั่นใจและความชัดเจนแบบสั้น ใช้ Reflection และบอกขั้นตอนถัดไปทีละข้อ และอย่าตำหนิในช่วงเวลาที่เจ้าของกำลังตื่นกลัว

คำถามให้นักศึกษาตอบก่อนเฉลย:

- ถ้าเจ้าของถามว่า "ให้กินนมได้ไหม" คุณจะตอบอย่างไรในสองประโยคที่ชัดและสุภาพ
- เมื่อเจ้าของชื่อยาไม่ได้ คุณจะถามอย่างไรให้ได้ข้อมูลที่ใช้ได้ในไม่กี่นาที
- คุณจะทำให้เจ้าของใจเย็นลงได้อย่างไรโดยไม่ทำให้เสียเวลา
